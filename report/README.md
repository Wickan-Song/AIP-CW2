# AIP304 CW2 Report (Option 2) — LaTeX project

Five-page PDF report for Coursework 2, Option 2 (research challenge):
does binary lesion-mask supervision improve rejection of held-out disease
classes on familiar hosts, relative to a matched baseline, when inference
uses only RGB images?

## Build

```shell
latexmk -pdf main.tex      # or: pdflatex + bibtex + pdflatex ×2
```

Requires a standard TeX Live / MacTeX installation (pdflatex, natbib,
booktabs, titlesec, microtype, hyperref). The compiled result is `main.pdf`
(exactly 5 pages, as required by the task sheet).

## Files

- `main.tex` — the report. All numbers trace to the frozen artifacts under
  `artifacts/formal/` (see the AI-use disclosure in §7 for the verification
  chain).
- `refs.bib` — 15 references. The ten coursework-related entries are copied
  from the task sheet's reference list (author initials as printed there);
  the five method classics (ResNet, MSP, AdamW, U-Net, V-Net/Dice) are cited
  for architecture and loss provenance.
- `figures/` — the five vector figures used, exported by
  `../report_figures.py` (300 DPI equivalent, audited for a 6pt readability
  floor, no clipped text, no tick collisions):
  - `fig3_paired_seeds.pdf` (183×108 mm, included at 0.82 linewidth)
  - `fig5_oscr_curves.pdf` (169×66 mm, included at 0.88 linewidth)
  - `fig7_host_confusion_report.pdf` (183×84 mm) — host-level 7×7 known-class
    confusion with readable counts (lesion-supervised arm, one panel per
    assignment); full 25×25 matrices and all four host-level panels are in
    the notebook, per the task sheet's "readable subset" guidance
  - `fig2_score_distributions.pdf` (183×66 mm, included at 0.97 linewidth)
  - `fig4_false_acceptance_destinations_top6.pdf` (183×78 mm; compact top-6
    variant, full top-10 version regenerates alongside it)
  The partition-composition figure (`fig1_data_and_design.pdf`) is also
  regenerated by the script but kept in the notebook to stay within five
  pages; its counts appear in §3 of the report text.
- `main.pdf` — compiled deliverable.
